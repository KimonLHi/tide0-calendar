This public repository contains generated calendar events only, not the private forecast source or configuration. Events are heuristic estimates at Santa Monica Beach near the Pier, calibrated to target about two qualifying windows per week; actual frequency varies by season. A calendar event requires at least two consecutive favorable hours. This is not a probability, beach-width measurement, or safety/water-quality assessment. Check current local conditions and official advisories.
